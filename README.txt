KHUSHI KI DUKAN - Frontend Fashion E-Commerce Demo

HOW TO RUN
1. Extract the ZIP file.
2. Open the purple-vogue folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (if installed),
   or double-click index.html to open it in your browser.

FEATURES
- Responsive fashion storefront
- Product categories and search
- Add/remove cart items
- Change product quantities
- Cart persistence using browser LocalStorage
- Checkout form and demo order confirmation

NOTES
- This is a frontend-only demo.
- No backend, real account system, inventory, or payment processing is included.
- Product photos load from Unsplash URLs, so internet access is needed for images.
- Cart data is stored in the browser where the site is opened.
